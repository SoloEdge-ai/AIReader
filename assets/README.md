# Application icon

Original AI-generated artwork selected and approved by the maintainer on 2026-09-22.
Direction: a charcoal rounded square, ivory open book, and a muted blue ribbon bookmark;
no text, AI sparkles, circuit motifs, or extra branding. Transparent outside the tile.

`icon-source.png` is the approved original. `app.ico` contains 16, 20, 24, 32, 40,
48, 64, 128 and 256 pixel PNG entries, preserving alpha. The same artwork supplies
the browser favicon. Regenerate with:

```
node node_modules/electron/cli.js scripts/build-icon.cjs
```

No generation service is involved in the format conversion.
