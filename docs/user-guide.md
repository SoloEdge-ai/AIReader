# 用户指南

空间桌面中可拖动 PDF 右侧的竖向手柄调宽，也可聚焦后按左右方向键；右下角调整宽高。文档底边会保持在当前阅读区内，收起工具栏也能调整。缩小窗口后再放大会恢复首选尺寸。旧版本若找不到底部手柄，可点右上角“∨”展开阅读工具栏，将“空间”切到“并排”，拖动两区之间的分隔条。

书库和阅读页顶部的“问题导航”可查找所有书的问题，按书籍、状态或问题／结论标题筛选，也可继续上次问题。查看未放置问题会打开笔记编辑器；跨书打开前先保存当前编辑内容。继续会恢复对应会话和问题，保留尚未发送的文字，不自动加入其他书的材料。

在问题卡片“状态与结论”或问题导航中点“检查材料更新”，核对上轮材料；新增材料须先在当前画布选中，再点“纳入当前画布选择”。生成差异后可展开对照新增、更新、未变化、缺失或移除的内容。确认加入的是清单中已经冻结的版本；原材料后来又修改时，先重新读取并生成。替换清除原材料／图片／选区，追加检查总量并保留已有材料，问题文字均保留；也可沿用上轮全部冻结材料。确认后回到问答，最后手动发送。旧结论和手选状态不会被自动替换。归档没有聊天时会说明没有比较基线，可选新材料重新开始。

持续研究可以从“工作区操作 → 新建问题”（窄工作台也可用“更多”）开始，或在回答详情中“保存为问题”。标题记录问题，正文写自己的总结；“继续探究”打开关联会话，不会自动提问。回答详情可“沿用本轮冻结材料”，也可从画布重新选中最新内容加入。旧回答需要作为 AI 笔记明确加入，才会进入严格材料范围。

回答详情的“收为结论版本”保留独立答案；在问题卡片“状态与结论”里选择当前结论与问题状态。新回答不会覆盖个人总结或自动替换旧结论。“从此回答分支新问题”保留原问题，使用新会话。归档没有原聊天，恢复后的问题继续时会创建新会话；结论及其来源仍可独立阅读。

在画布上选中材料后，点“问 AI”可以准备解释、比较或检查依据的问题。已有输入会保留，选择追加或替换后再继续；点击“加入本轮问题”核对材料，最后点击发送。快捷提问默认“仅所选材料”，需要本书其他内容时可在范围菜单选择“结合本书检索”。没有核验文字引用的材料会明确提示。

回答完成后点“保存到此处”，会在发起材料附近保存一张 AI 笔记卡片。保存成功后可点“查看卡片”，也可通过工作台撤销。结果卡片的“使用材料”保留当时的内容，选中卡片可查看“用于回答”的连接；这条线说明使用记录。正文仍可在原有笔记编辑器中修改，AI 来源继续保留。

当前版本使用 v6 数据库，不会自动迁移或删除旧书库；旧版数据需另行处理。更新程序本身不会清理本机账号目录或原始 PDF。

编辑已有笔记时可选择“展开编辑笔记”。展开层、材料列表及新个人卡片显示同一份内容，可以同时打开问答浮窗继续讨论；收起前自动保存，失败时保留草稿并显示重试入口。

安装当前用户版或运行便携EXE，再导入PDF。导入复制到本地书库，未登录可阅读/搜索/批注/笔记。扫描页无OCR但可框选区域。

默认指针拖动视野，文字工具选择原文。Ctrl+滚轮缩放，右键拖动临时平移，Esc回指针。选文可摘录或标注；区域工具可截取图、表、公式和文字。来源页码回原文，个人评论不修改摘录。点击顶部问答按钮打开应用内浮窗；拖动顶部标题栏移动，拖动边角改变宽高，方向键可微调，标题栏可重置或关闭。位置与尺寸按书籍记住，关掉浮窗不清除会话。

笔记详情的“放到画布”会建立引用同一笔记的卡片；重复点击定位已有卡片。卡片选中后可编辑或展开。“移除卡片，保留笔记”只移除个人卡片位置；“删除笔记”同时删除其个人卡片和关系，可撤销。原文／图片摘录卡片点击“写评论”创建笔记；旧卡片已有的纯文本评论点“编辑评论”时原样转入笔记。摘录的原文／图片不能在评论中修改；删除摘录卡片不会删除已有评论，笔记仍保留原文位置。旧独立个人卡片点击“编辑笔记”后保留原文字并转入富文本 Note；未点击的旧卡片仍可阅读。

高亮等标注不会自动产生空笔记。点击标注或列表条目，再点“写评论”即可添加笔记。删除批注保留评论和原文位置；删除笔记保留批注。已删除源标注会明确提示，仍可通过页码返回原文。

启用问答需准备组件并独立登录ChatGPT。选择模型/强度，添加原文、截图或个人材料并查看预览后发送。移除问题材料不删除原对象。引用显示本轮证据，可回跳；个人材料不自动成为作者原文。回答可存带来源笔记。

保存失败保留草稿，重试后再切书/关闭。工作区包用于恢复本书与空间笔记，不含账号/完整聊天。笔记可导出Markdown资源包。安装/便携版共享本地数据；版本渠道和已知限制见发布说明。
