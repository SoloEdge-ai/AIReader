# 用户指南

重构分支提示：此分支使用新的 v5 数据库，暂不直接打开旧版书库，也不会自动删除它。体验包应使用独立数据目录；本机替换安装和旧测试数据处理是单独步骤。目前还不是正式升级交付。

编辑已有笔记时可选择“展开编辑笔记”。展开层、侧栏及新个人卡片显示同一份内容，可以切换侧栏到问答继续讨论；收起前自动保存，失败时保留草稿并显示重试入口。

安装当前用户版或运行便携EXE，再导入PDF。导入复制到本地书库，未登录可阅读/搜索/批注/笔记。扫描页无OCR但可框选区域。

默认指针拖动视野，文字工具选择原文。Ctrl+滚轮缩放，右键拖动临时平移，Esc回指针。选文可摘录或标注；区域工具可截取图、表、公式和文字。来源页码回原文，个人评论不修改摘录。

笔记详情的“放到画布”会建立引用同一笔记的卡片；重复点击定位已有卡片。卡片选中后可编辑或展开。“移除卡片，保留笔记”只移除画布位置；“删除笔记”同时删除其卡片和关系，可撤销。旧独立卡片及原文／图片摘录评论暂时保持原有编辑方式。

高亮等标注不会自动产生空笔记。点击标注或列表条目，再点“写评论”即可添加笔记。删除批注保留评论和原文位置；删除笔记保留批注。已删除源标注会明确提示，仍可通过页码返回原文。

启用问答需准备组件并独立登录ChatGPT。选择模型/强度，添加原文、截图或个人材料并查看预览后发送。移除问题材料不删除原对象。引用显示本轮证据，可回跳；个人材料不自动成为作者原文。回答可存带来源笔记。

保存失败保留草稿，重试后再切书/关闭。工作区包用于恢复本书与空间笔记，不含账号/完整聊天。笔记可导出Markdown资源包。安装/便携版共享本地数据；版本渠道和已知限制见发布说明。
