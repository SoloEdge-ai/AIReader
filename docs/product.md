# 当前产品行为

状态：描述 `codex/liquidtext-alignment` 实现分支的当前行为；完整验收条件见[对齐计划](plans/liquidtext-alignment.md)。

画布问答阶段 A 已接入当前工作区，详细设计与后续阶段见[无限画布与 AI 知识问答](plans/canvas-inquiry.md)，验证范围见[实施记录](verification/2026-10-20-canvas-inquiry.md)。阶段 B 的问题卡片、结论历史、材料更新差异清单与全局问题导航已接入本分支；跨书材料问答仍是后续规划，导航不会建立跨书模型上下文。

问题卡片复用 Note，标题是问题，正文保留个人总结；AI 回答独立保存为结论版本。可新建空白问题、把回答保存为问题、从回答分支新问题，手动设置待探索／探索中／已有结论／待复核及当前结论。继续探究仅打开关联会话；用户显式沿用某轮冻结材料时创建新的快照，不自动发送或带入旧回答。检查材料更新以本问题最新归属轮次为基线，明确选择新增或移除材料，再冻结最新版本并比较文字、来源和图像。确认追加或替换的是清单中的冻结内容，不重新读取，也不改写旧结论或自动改变状态。移出卡片保留问题，删除问题不删除聊天、证据和结论。归档恢复保留问题与结论引用，原聊天不入包，继续时创建新会话并明确没有轮次材料基线。

书库与阅读工具栏的“问题导航”汇总本地书库问题，按书籍、状态和问题／结论标题筛选，区分已放置和未放置，显示最近探究。可查看问题、继续会话或检查材料更新；切书前必须保存当前笔记与工作区。最近访问单独持久化，不改写问题正文和结论。未放置问题仍可编辑和续问，不自动放回画布。

选择画布材料后可用“问 AI”准备解释、比较、检查依据或自定义问题。检查依据先明确指定笔记，快捷动作不立即发送；已有问题提供追加／替换／保留操作。画布快捷提问默认“仅所选材料”，只能分析明确加入的冻结材料和图片，不加入当前页、相邻文字、导航、记忆或旧对话；信息不足时明确说明。原文摘录的文本引用仅在 Core 核对选定文字与位置后提供，不能用所在页的其他内容补足。用户可明确改为“结合本书检索”，原有阅读范围也在同一入口选择。

多选集合在同一版本冻结，关系保留端点身份，材料仍可逐项移除；移除时保留其余项目的原快照，并排除缺少端点的关系与不再使用的图片。AI 笔记再次提问保留生成身份与编辑状态。回答完成后可“保存到此处”，在发起材料当前边界右侧或下方寻找空位；起点已不存在时使用冻结边界或当前视野，用户可再拖动调整。保存以书籍级命令同时提交笔记与位置，材料使用关联保存在笔记的历史来源中；选择结果卡片可查看“用于回答”连线及冻结材料，不自动创建“支持”关系。重复保存复用已有回答笔记，已放置时提供“查看卡片”；普通“存为笔记”保留在回答详情中。

Windows 11 x64、中文界面，一个 PDF 一个工作台。默认左侧原文、右侧自由画布，同屏显示、各自滚动与缩放；导航收起后两区平分剩余宽度，窄窗切换原文／工作台页签。卡片使用工作台坐标，不再避让 PDF 的旧中央柱。两区可临时最大化，恢复后按每书分区比例继续。未登录可阅读、搜索、批注和记笔记。

阅读页左侧可收起导航显示目录、书签、搜索、本书材料、批注和笔记。AI 问答沿用可移动、可缩放的应用内浮窗；关闭后从工具栏重开，位置按书保存。选择材料时，虚线指向浮窗的本轮材料入口；明确加入后，线变为实线。浮窗不会因选中卡片而自动打开。材料库按全部／摘录／笔记／绘图筛选，也可按主题组筛选；移出工作台的卡片保留在材料库并可放回。材料可显式加入问题；主题组先展示成员清单，再由用户确认加入。导航宽度和分区比例按书记住。界面风格有专业中性／温暖纸感两套，与浅色／深色／跟随系统独立组合。

PDF.js 渲染，后台提取建立本地全文检索；扫描页可阅读/框选，没有 OCR。原文锚点绑定 PDF 指纹和物理页，不依赖可重建片段 ID。文字和图表摘录保留不可编辑的原文身份，来源按钮先预览、再明确前往 PDF。2–3 份摘录可临时并排比较；原文聚焦以原始 PDF 页面裁剪相关区域，显示省略分隔和上下文扩展。笔迹可跨页面和白板，一笔一个逻辑对象；源批注不可移动到其他原文。

笔记列表、新建的个人笔记卡片和“展开编辑笔记”共用实时富文本草稿；展开层占工作台，PDF 和问答浮窗继续可用。收起前保存，失败保留展开层和草稿。正文支持表格、行内与块级 LaTeX 公式；来源引用由 Core 从本书对象冻结，正文只存引用 ID。高亮、下划线、删除线和区域标注不自动生成空笔记；选择标注后点“写评论”才创建关联笔记。删除标注保留评论及来源说明；删除笔记保留源标注，同时删除本笔记的画布位置和关系，撤销原子恢复。移出卡片只改变放置状态，保留摘录或笔记、来源和关系；从材料库放回后恢复原位置。摘录可关联多篇笔记，一篇笔记也可引用多份摘录；原文始终是只读来源。

AIReader 下载校验固定 Codex 组件，用应用专属目录独立登录，不复用系统凭证。模型与强度由服务提供，发送时冻结。编程工具隔离未通过，保持禁用。

材料加入时冻结；发送时冻结阅读范围、模型及集合。默认约 12000 文本 tokens、20 材料、4 图片。超限提示，旧图像/材料不无限重发。原文/个人/AI 内容明确区分；引用只来自 Core 已验证证据。公开推理摘要不作为原文或后续提示词。

数据在 LOCALAPPDATA/AIReader，由 Core 管理。安装/便携版共享数据。此分支使用 DB v6、工作区快照 v5、布局 v3、归档 v4。用户已允许放弃旧笔记与工作区兼容；程序拒绝旧数据库和 v1–v3 归档，不自动清空或覆盖旧文件。测试使用隔离数据目录。归档包含本书 PDF、主题组、来源引用及相关资源，不含账号或完整聊天。

不含跨书材料问答、云同步、OCR、触控专项、局部橡皮、自动更新或回写标注 PDF。
