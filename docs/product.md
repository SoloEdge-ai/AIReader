# 当前产品行为

状态：描述已交付行为，重构目标见[计划](plans/architecture-refactor.md)。

Windows 11 x64、中文界面，一个 PDF 一个工作区。PDF 是共享画板的固定阅读轴，移动视野，卡片避开正文。未登录可阅读、搜索、批注和记笔记。

阅读页左侧可收起导航显示目录、书签、搜索、批注和笔记；中央为 PDF／白板，右侧仅问答。宽窗口可同时打开左右两栏；窄窗口交替打开两侧抽屉。左栏宽度按书记住。当前“材料”列表尚不包含所有画布卡片和绘画对象。

PDF.js 渲染，后台提取建立本地全文检索；扫描页可阅读/框选，没有 OCR。原文锚点绑定 PDF 指纹和物理页，不依赖可重建片段 ID。笔迹可跨页面和白板，一笔一个逻辑对象；源批注不可移动到其他原文。

笔记列表、新建的个人笔记卡片和“展开编辑笔记”共用实时富文本草稿；展开层位于阅读工作区，不阻止使用右侧问答。收起前保存，失败保留展开层和草稿。高亮、下划线、删除线和区域标注不自动生成空笔记；选择标注后点“写评论”才创建关联笔记。页内便签属于显式写笔记动作，会打开评论。删除标注保留评论及来源说明；删除笔记保留源标注，同时删除本笔记的画布位置和关系，撤销原子恢复。移除个人卡片只移除位置，笔记内容保留；重复放置定位已有卡片。原文／图片摘录卡片的评论也可显式转为同一 Note 内容，原文仍是独立、不可编辑的来源；删除摘录卡片后评论与冻结来源保留。旧独立个人卡片首次编辑时同样转入 Note；尚未进行启动时批量迁移。

AIReader 下载校验固定 Codex 组件，用应用专属目录独立登录，不复用系统凭证。模型与强度由服务提供，发送时冻结。编程工具隔离未通过，保持禁用。

材料加入时冻结；发送时冻结阅读范围、模型及集合。默认约 12000 文本 tokens、20 材料、4 图片。超限提示，旧图像/材料不无限重发。原文/个人/AI 内容明确区分；引用只来自 Core 已验证证据。公开推理摘要不作为原文或后续提示词。

数据在 LOCALAPPDATA/AIReader，由 Core 管理。安装/便携版共享数据。本重构分支已使用 DB v5、工作区归档 v3。旧数据库不自动迁移或清空，体验此分支需独立数据目录，实际安装与旧测试数据处理另行交付。归档包含本书 PDF、空间内容及资源，不含账号或完整聊天；v1/v2 旧包不在本分支恢复。

不含跨书、云同步、OCR、触控专项、局部橡皮、自动更新或回写标注 PDF。
