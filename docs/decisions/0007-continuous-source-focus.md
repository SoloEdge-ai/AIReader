# ADR 0007：在连续原文中定位来源

状态：已实现，替代此前原文聚焦的裁剪阅读视图。

## 决定

2026-09-30 用户明确原文区域应始终整页平铺。此前“聚焦原文”隐藏阅读器并展示来源附近的裁剪片段，产生第二层卡片和上下文操作，打断连续阅读。

选区、摘录卡片、搜索和工作台菜单的聚焦入口统一在当前 PDF 中定位并高亮来源。页面顺序、缩放和可见文档矩形保持原状；多处来源同时标记并先定位第一处。原文标题栏只增加返回箭头，恢复定位前的阅读位置并清除高亮。普通来源引用使用同一流程。窄窗或工作台最大化时先显示原文，页面布局就绪后再滚动。

## 边界

复用 `BookWorkspace` 的来源定位和 `PdfReader` 的原始 PDF 坐标变换、文字层与高亮覆盖层，删除独立的聚焦文档、裁剪模型和渲染器。定位和返回只改变阅读视口，不修改来源、卡片、笔记或书籍内容。并排比较继续作为工作台临时视图。

浏览器验收使用生成的多页 PDF 和真实 Core，覆盖连续并排、空间桌面高缩放、选区与卡片入口、多来源高亮、返回位置以及窄窗隐藏原文后的定位。
