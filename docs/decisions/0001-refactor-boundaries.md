# ADR 0001：统一内容与编辑事务

状态：已接受，分阶段实现。日期：2026-09-24，基线d7fcbc2。

当前Note/WorkspaceCard重复保存个人内容，跨对象删除/undo靠两套保存机制协调；UI/Core入口职责混合，旧文档互相矛盾。

决定：统一Note内容、Placement只保存空间呈现；标注可无Note。BookEditingSession协调草稿/命令/历史，Core应用操作统一事务与幂等。几何/手势从React/PDF.js解耦。保留技术栈与已有来源/冻结边界。

一个重构分支，阶段preview，同一安装身份，不更新Latest，最后一个squash PR。当前测试库可清理、不做旧格式迁移；不是以后任意数据可删除的永久规则。

新增类型必须覆盖schema/事务/呈现/材料/归档。文档围绕实际行为维护，历史归档。成功按行为完整、所有权和保存一致性衡量。
