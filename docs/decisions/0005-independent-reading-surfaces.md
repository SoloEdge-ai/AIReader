# ADR 0005：独立原文与工作台视口

状态：独立数据坐标与视口仍有效；固定双栏呈现被 [ADR 0006](0006-continuous-desk.md) 替代。

## 背景

单张世界画布中嵌入 PDF 柱可以共享笔迹坐标，却迫使摘录卡片避让 PDF，也让原文和整理材料随同一相机缩放。用户需要原文和工作台并排、各自滚动缩放，并能在来源与摘录之间迅速回查。LiquidText 的并排阅读与工作区说明了这一任务路径，但 AIReader 保留自己的笔迹、笔记和 AI 浮窗实现。

## 决定

`BookWorkspace` 在同一书籍编辑会话中挂载两个 `PdfReader` 表面：原文实例渲染 PDF 页面与其批注，工作台实例只渲染白板对象。PDF 页内位置、PDF 缩放、画布相机、画布缩放、分区比例和 AI 浮窗矩形分别保存为阅读偏好；它们不增加工作区内容版本，也不进入内容撤销历史。窄窗以页签呈现两区，切换时不销毁另一侧状态。

来源以 PDF 原生页码和坐标保存。来源、永久关系以及当前 AI 问题材料的线由 renderer 从现有对象和视口端点投影生成；滚动、缩放或浮窗移动只重算屏幕几何，不写入第二份来源或关系。选中材料的虚线只是候选预览，只有 Core 成功冻结并加入本轮问题后才显示实线。页面未就绪时先保留待定位来源，布局出现后完成滚动。

主题使用独立的风格偏好（专业中性／温暖纸感）与浅色／深色模式组合。组件尺寸、字阶、交互、焦点和来源身份保持相同，颜色与纸面层次由语义变量提供。PDF 原页不反色；原文、个人笔记与 AI 笔记还通过文字和图标区分。

旧白板对象保留世界坐标；不把旧 PDF 柱占据的世界区域当作禁区，也不迁移或伪造跨表面笔迹。拆分后 PDF 分段和工作台分段按同一逻辑 stroke 身份处理。格式处理见 [ADR 0004](0004-workspace-groups-and-format-v6.md)。
