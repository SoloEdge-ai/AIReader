# ADR 0003：问答作为应用内浮窗

状态：已决定，实施于 PR #24 合入后的独立迭代。

阅读画板需要完整宽度；固定右栏随展开改变 PDF 排版和可见范围。问答改为覆盖在 AIReader 阅读页面内的浮窗，而非独立的 Windows 窗口。左侧材料导航可与问答同时打开。默认放在右上，标题栏负责移动，四边和四角负责连续调整大小；尺寸、位置按书籍保存，应用窗口缩小时只约束可见位置，不破坏原有持久矩形。提供重置和关闭，关闭不删除会话或问题草稿。

浮窗只是 renderer 布局状态。聊天消息、来源引用、材料冻结、模型选择、Core 账号和保存边界均沿用原实现。截图框选时暂时隐藏浮窗以露出页面，完成或取消后恢复。未来若支持多浮窗／独立系统窗口，应另行决定焦点、跨窗口草稿和书籍隔离语义；本次不扩展。
