# 问题卡片与结论版本

状态：接受，2026-10-20；阶段 B 的首个实施切片。

问题以 `Note.question` 保存身份和探究元数据，画布仍使用引用该 Note 的轻量位置。标题是问题，正文是个人总结；回答继续独立保存为带 AI 来源的 Note，不覆盖总结。问题状态由用户设置为待探索、探索中、已有结论或待复核，模型完成不改状态。

元数据保存同书会话、起点轮次及问题全文、结论 Note 列表、当前结论和可选父问题。卡片标题最多 200 字符，起点问题全文另存只读来源，避免长问题在归档后丢失。从聊天保存问题复用该会话；从已有问题分支创建新会话。空白问题创建时即拥有独立会话；归档恢复后首次继续才创建新会话。创建、状态、选择结论、绑定会话和删除恢复均经书籍命令及回执；正文继续使用已有笔记保存队列。问题移出画布仍保留，删除问题不删除聊天、证据或结论。

继续入口只打开关联会话，不发送。用户可显式沿用某一轮的冻结材料；Core 为实际发送内容复制新的未提交材料 ID 和图像，不能复用已提交 ID，也不重新读取最新内容。原版本、模型、范围与旧回答不变。更新最新材料仍由用户在画布明确选中并加入，不隐式刷新或扩大集合。

本切片实现问题、状态、结论历史、会话恢复和历史冻结材料沿用。自动比较最新材料的变化清单、重开后的全局问题导航属于后续 B 切片，不把它们报告为已实现。分支保留父问题引用；父问题删除后子问题独立存在。

归档增加可选问题元数据并重映射同包问题／结论引用；归档不含聊天，恢复时清除会话与轮次绑定，继续入口创建新会话并明确说明。丢失／已删结论显示不可用，不能错误指向其他书籍。数据库、工作区、归档版本保持不变，未包含新字段的现有内容按原方式读取。
