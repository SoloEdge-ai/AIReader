# 材料更新审阅与全局问题导航

状态：接受，2026-10-20；阶段 B2。

全局导航列出本地书库中的活跃问题，支持按书籍、状态及标题筛选，显示最近探究、当前结论和是否放置。它只聚合导航元数据；打开另一书籍前沿用保存与退出保护，不建立跨书材料或模型上下文。最近访问由 Core 按 book/question 保存，不改变问题状态、正文或结论。

轮次新增可选 questionId，由 Core 验证同书、同会话后冻结。问题的材料基线取最新归属轮次；兼容 B1 时回退到该问题明确收录的结论轮次及起点轮次，不把共享会话的其他问题当作本问题。归档没有聊天时明确无轮次基线，用户仍可加入当前书的材料。

审阅先取得基线与当前可用目标，用户明确纳入新增选择并控制数量，再生成最新材料快照和差异清单。Core 负责冻结、来源身份和像素比较；个人标记预览仍由 renderer 提供并保留其身份。差异为新增、内容更新、未变化、原对象缺失、用户移除；移动卡片或重建索引不自动视为正文变化。关系必须保留两个端点。

审阅结果中的最新内容已经冻结。确认后只把这批快照追加或明确替换到问题草稿，不重新读取对象，不自动发送。沿用旧版本则复制历史有效材料为新 ID。替换与追加的材料／图片／选区边界必须清楚，保留已有问题文字；失败和书籍切换不丢草稿。旧回答、结论及其材料永不改写，变化不自动标记结论错误或重跑模型。

DB6、workspace5、archive4、API2 保持不变，新增轮次字段和独立导航记录均为可选扩展。归档继续不包含完整聊天或导航历史。
