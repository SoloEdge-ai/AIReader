# ADR 0004：主题组身份与 v6 数据格式

状态：已实施。

工作台主题组采用独立、单层的 `WorkspaceGroup`，保存标题、颜色、边界、成员顺序和折叠状态。成员仍是原卡片或完全位于白板的绘图对象；关系始终指向这些真实对象。折叠组时 renderer 可以把线投影到组边缘，但不得把持久端点改为组 ID。这样展开、折叠和重新布局不会改变用户表达的关系含义。

一个对象最多属于一个组。Core 在按书命令事务中验证成员存在性与白板资格；删除成员会产生组成员列表的实际差量和逆操作，删除组则只删除容器。Note 删除／恢复位置同样保存组归属，避免留下悬空成员。

此次格式直接升级为 DB v6、workspace v5/layout 3、归档 v4。产品决定不转换旧笔记和工作区，因此 Core 在打开数据库前只读检查版本，明确拒绝 DB v5 及更旧版本且不修改、不备份、不清理原文件；归档只接受 v4，v3 及更旧版本在恢复副本前拒绝。视野、分区比例、独立 PDF／画布缩放和聊天浮窗继续属于阅读偏好，不进入工作区内容版本或撤销历史。
