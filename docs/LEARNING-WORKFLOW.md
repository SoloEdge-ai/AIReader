# 可回源的阅读学习流程

## 1. 回答成为笔记

- 在已完成的回答下提供「存为笔记」；保存为当前书籍的可编辑富文本笔记，不自动保存全部聊天。
- Core 从真实已完成的回答创建笔记；保留 AI 生成身份、原问题、模型（若有）、已经校验的出处与原文快照。无有效引用时明确没有可核验出处，不制造链接。
- 重复保存同一回答定位到同一未删除笔记，不覆盖用户修改。切书、重启后仍可查找、编辑和回到 PDF 原文。
- 笔记支持导出 ZIP，包含 Markdown、实际关联的本地图片、书名及出处页码。用户先保存当前编辑；失败时保留草稿且不导出陈旧版本。
- 原始 PDF 不改写；导出不含凭证、推理摘要、无关聊天上下文和其他书籍。图片仅来自 Core 管理的本笔记批注或原问题附件；前端不能指定任意文件路径。

## 2. PDF 图表就地提问

- 在 PDF 中框选区域，显示图片、原书页码和来源位置，加入当前书籍当前会话的问题草稿。
- 复用现有图片预览/移除、上限和错误处理；用户确认发送，不在选择时自动调用模型。
- 选区、截图、页码、模型在发送时冻结；切书或后续滚动不能改写已发送材料。
- 图像保存 PDF 指纹、物理页和 PDF 坐标；普通粘贴图片仍是用户附件，不伪造书中出处。图像定位不等于模型解释已获原文支持。
- 旋转、缩放、高 DPI 和扫描页均使用真实画布区域；支持取消框选，不能影响已有区域批注。

## 3. 引用预览与返回阅读位置

- 回答中的有效引用可预览已发送的原文片段与页码，并明确操作以跳至原文；无效引用不可点击。
- 预览支持鼠标与键盘、关闭与焦点恢复，在窄窗口内可用。
- 引用/笔记来源跳转后可返回跳转前的阅读位置（保留页内位置）；历史限定当前书籍，切书清空，不混入其他书籍。
- 原文坐标失效时退化至正确页级定位。公开推理摘要不是引用校验，不改变现有事实边界。
