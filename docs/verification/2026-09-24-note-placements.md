# 个人笔记卡片引用验证

状态：接续 0c50661 的阶段 2 切片。个人卡片引用 Note 已实现，不代表全部 Note／placement、统一命令或三栏 UI 完成。

## 行为与回归

- Core HTTP 先验证带 noteId 的个人卡片，旧 schema 拒绝；接入引用后继续验证删除 Note 级联删除位置／关系，旧实现失败，再补事务协调。移除卡片保留 Note，恢复 Note 同事务恢复位置及关系；关系端点缺失时整体回滚。
- 拒绝跨书、失效 Note、重复放置、卡片第二份正文。材料按 Note revision 读取／冻结正文，修改原笔记不改变已冻结内容，旧版本材料请求被拒绝。归档恢复副本重映射 Note 引用。
- Renderer 验证卡片、侧栏、展开层实时共用草稿，重复放置不增加卡片，独立移除、删除／撤销及重新打开保留内容。
- 新 UI 用例揭示开发模式 CORS 预检漏掉现有 PUT 方法，导致视野保存阻止放置；增加 PUT 许可，来源／会话校验不变。
- Standards 审查发现正文 Shift＋点击冒泡取消卡片选择，卸载编辑器；真实浏览器用例先失败，排除编辑控件事件后通过。
- Spec 审查发现刷新 GET 返回可覆盖期间的新画板编辑；延迟真实 HTTP 响应的 renderer 用例先失败，响应端复查请求序号／编辑代次／已提交基线后通过，保留草稿及本地视野。
- 全量 UI 首跑暴露旧测试假定首张卡片就是它的 fixture；改为按 draft-card ID 操作，并通过返回书库完成新增用例清理保存。未放宽产品断言。
