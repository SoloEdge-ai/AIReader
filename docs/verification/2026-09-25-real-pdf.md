# 私有 516 页 PDF 本机验收（阶段 5，部分）

使用 `node --import tsx scripts/manual-pdf-acceptance.ts <本机 PDF 路径> 14 <1|1.5|2>`。脚本把书导入系统临时目录、启动真实 Core 和 Edge 渲染页，结束后删除自己的临时书库；截图仅写入忽略的 `.local/screenshots`，不提交 PDF、提取文本或截图。此次输入是用户此前指定的 516 页技术书；只记录元数据和时长，不公开其路径与内容。

环境：Windows 11 `10.0.26200`、Intel Core Ultra 7 155H、32 GiB RAM、Node 24。五次独立导入，页面 14 在 1440×900 CSS 视口下打开，分别用浏览器设备像素比 1、1.5、2：

| 设备像素比 | 解析至 ready | 打开阅读页 | 页 14 Canvas |
| --- | ---: | ---: | --- |
| 1（三次） | 4.01–4.24 s | 0.49–0.60 s | 已出现 |
| 1.5 | 3.96 s | 0.46 s | 已出现 |
| 2 | 4.14 s | 0.64 s | 已出现 |

Core 进程在五次打开时 RSS 约 208–228 MiB。人工检查截图：第 14 页正文、图示、页码、工具盘均可见，没有明显文字块错位或图像缺失。此检查使用**浏览器设备像素比**，不等同于 Windows 桌面 100%／150%／200% 显示缩放验收；未测长时间滚动、连续绘画、安装版或 AI。阶段 5 仍未完成。
