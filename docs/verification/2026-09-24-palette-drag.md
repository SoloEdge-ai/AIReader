# 工具盘拖动验证

状态：阶段 3 局部验证，尚未覆盖所有窗口尺寸和 Windows 缩放。

- Playwright 独立工具盘夹具：从底部用手柄拖到左侧，停靠位置和手柄可见区域正确。
- Playwright 真实阅读页：加载生成 PDF，手柄拖到左侧，返回书库再打开后停靠仍为左侧。说明基础拖动逻辑没有被 PDF 层或阅读页事件拦截。
- 更改后的完整浏览器套件 20 项通过；归档格式改动曾暴露 Node JSON 导入要求，已在同一套件中修复并重跑。
- 手柄从低对比度的小点改为更清晰的六点图标，使用抓取／拖动光标及 `touch-action: none`。仍只允许从独立手柄拖动，避免点工具时误移动工具盘。
- 尚未在用户当前安装版本、各 DPI 和窄窗口手动复核；不能据此推断此前无法拖动的具体环境原因。
