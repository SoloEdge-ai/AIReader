# UI 与交互规范

状态：`codex/liquidtext-alignment` 实现分支的交互规则；验收记录与尚有限制见[对齐计划](plans/liquidtext-alignment.md)。

专业中性与温暖纸感两套语义色，分别组合浅／深／跟随系统，PDF 保留原色。两套风格共用布局、字阶和控件，不靠颜色单独区分原文、个人笔记与 AI 笔记。工具图标18–20px、命中区至少36×36px；主题、排版、间距、焦点、圆角、阴影使用统一语义变量。

`apps/web/src/ui` 已集中 Icon、Popover 和浅深主题颜色 tokens；工作区操作菜单、对象格式、工具盘的添加／形状菜单与选区、模型浮层共用原生顶层 Popover。画笔设置保留首次选择、再次单击打开的工具行为，但复用同一浮层表面和视口定位规则。定位模块封装上下左右相对位置及视窗约束；菜单提供键盘焦点与 Esc 关闭，对象格式表单打开时聚焦第一个控件，并在工作区缩放后的布局提交后重新定位。横向及左右停靠的菜单／画笔设置已有浏览器回归测试。`WorkspaceObjectActions` 与 `WorkspaceRelationActions` 分别拥有对象格式、关系编辑和操作条，复用选区条的基础表面、按钮命中尺寸、边框和阴影；文字选区与已选源批注共用一份颜色配置及色点弹层，画布对象也用同一弹层并保留自定义色。操作条的更多布局约束尚待统一。画板内容随世界缩放，菜单和手柄保持屏幕尺寸。工具盘约束在阅读区域，收起后位于原收起按钮位置；独立夹具与真实阅读页已验证手柄拖动、停靠和重开保持，并增强了手柄视觉与抓取指针，其余窗口尺寸和 DPI 仍待验收。

默认指针，显式进入选文。右键移动超过5px临时平移，静止点击保留菜单；中键和Space+左键也平移。Ctrl+滚轮以鼠标锚点缩放40%–300%，Shift+滚轮水平滚动。输入框/Tiptap/IME拥有编辑按键。

Esc优先交给IME/模态，再关闭弹层、取消手势或结束编辑，最终回指针；关闭画笔设置的第一次 Esc 保留当前笔，第二次才回指针。不删除完成对象和问题材料。pointercancel/失焦清理手势。V/T/R/P/H/E/L切换工具，编辑器优先处理撤销。

PDF 页渲染完成不代表书籍工作区数据已载入。就绪前的画笔或对象编辑手势不捕获指针、不创建半成品，并显示“工作区尚未就绪”提示；就绪后才能开始。界面保留独立的工作区加载／保存状态，不能把等待误报为已保存。

保存失败与笔迹／导出错误固定在阅读容器的反馈层，不随 PDF 滚动；提示高于问答浮窗，限制高度并可内部滚动，在高缩放下仍能触达重试、备份和关闭按钮，同时避开底部工具盘。提示本身阻止点击穿透，避免误触被覆盖的内容。重试保存后仍可继续标注。

打开选区菜单冻结文字和PDF坐标；取消选区自动隐藏操作条。AI动作只加入草稿。矩形区域支持图表/文字/公式混合，限定单页；包含个人标记明确标识。

引用预览冻结证据，定位后可返回阅读位置。聊天使用短用户气泡和开放回答排版，来源/材料/详情按需展开。

当前阅读页把目录／书签／搜索／材料放在可收起的左导航。PDF 与自由工作台位于独立面板，默认各占剩余宽度的一半；分隔条按书保存、可拖动并可用方向键调整。两区分别缩放、滚动和最大化；窄窗用页签切换，两边阅读与画布状态不丢失。左导航宽度每书可调 220–320 px、初始 240 px。第一眼应同时看清原文与整理对象，卡片原文不可直接编辑，来源先预览再定位。

问答以应用内部浮窗显示，默认靠右上，拖动标题栏移动、拖动边角调整宽高；窗口缩小时保持在可见范围，底部初始避开常驻工具盘。标题栏提供恢复默认位置和关闭；关闭不删除会话或已加入的问题材料。浮窗位置与尺寸按书保存，重开恢复。选中材料显示指向本轮材料入口的虚线，明确加入且 Core 冻结后显示实线；发送后草稿连线清除。窄窗口仍可同时打开左导航与问答浮窗，框选聊天截图时暂时隐藏浮窗，完成或取消后恢复。

左侧画布材料在同一列表列出卡片、笔迹、文本、形状及关系，可按类型筛选、按物理页码或类型排序；点击定位，显式“＋”加入本轮提问。主题组先展示实际成员清单，再由用户选择并确认冻结。对象列表分批展示，避免 5000 个对象同时创建 DOM。批注和笔记仍在下方独立列表；选择笔记只切换预览，不自动滚动 PDF。

标注与评论分离：没有评论的标注仍出现在列表，显示“无评论”；点击只切换材料预览，不滚动 PDF，并显示原文与“写评论”入口。评论详情分别提供“删除笔记”和“删除批注”；只有显式点击来源按钮才定位 PDF。源标注已删除时保留来源展示和跳页，提示已删除，并禁用标注颜色修改／加入批注材料。

富文本正文只在“展开编辑笔记”中编辑；材料栏和画布卡片始终是轻量预览，选中卡片不会挂载第二个编辑器。展开页占据工作台区域，正文保持适合长文阅读的宽度，底部保存状态固定可见；PDF、左侧材料和问答浮窗仍可使用。标题与正文优先，annotationSource、sourceCard、sourceReferences 和 AI 回答 origin.sources 统一收在“来源 · N 处”的只读 details 中；可显式回到原文，并把 Core 来源 ID 插入正文。编辑器支持表格和显式的行内／块级 LaTeX 公式；点击渲染后的公式再次编辑源码，不把普通 `$` 文本自动猜成旧公式。关闭按钮或编辑层内 Esc 先保存，失败不关闭，输入法组合期间不接管 Esc。移除个人卡片保留笔记；删除笔记会删除其位置、主题组归属与关系。摘录卡片始终展示不可编辑的原文／图片以及关联笔记数量与入口，不嵌入另一份正文编辑或预览。

桌面关闭窗口时先冻结界面并保存当前书籍的笔记与画板草稿；失败则保留窗口、解冻编辑并提示重试，成功后才退出。普通浏览器开发调试仍使用未保存草稿的离开提示。

工作台主题组是单层结构。框选材料后创建组，组头可改名、换色、折叠、整体拖动、自动排列和解散；一个对象最多属于一个组。折叠仅改变显示，关系端点仍指向原对象。自动排列按来源页码、再按成员顺序确定位置，完成为一次工作台撤销操作。卡片正文可选字，移动只从标题开始；右下角缩放手柄与底部操作按钮留有独立命中区域。可见区域以外的卡片和非笔迹对象不挂载 DOM。

选择 2–3 份文字或图表摘录可进入临时并排比较；退出不改动卡片位置。原文聚焦使用 PDF 原始画面与文字层，以来源上下 72 PDF points 作为初始上下文；同页重叠合并、跨页保序，省略处可展开上下文或整页。退出聚焦恢复原阅读位置，明确“前往原文”则留下返回入口。摘录支持选区按钮与拖入工作台两种放置方式；取消拖动、无效落点或切书不创建卡片。
