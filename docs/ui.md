# UI 与交互规范

状态：当前规则；新版布局见[计划](plans/architecture-refactor.md)，未实现前不作为功能声明。

中性灰、细边框、系统字体、线性图标；浅/深/跟随系统，PDF 保留原色。工具图标18–20px、命中区至少36×36px；主题、排版、间距、焦点、圆角、阴影使用统一语义变量。

`apps/web/src/ui` 已集中 Icon、Popover 和浅深主题颜色 tokens；其余按钮、工具设置和对象操作条的统一仍在实施中。目标是工具盘、选区／区域／对象条共用基础组件。画板内容随世界缩放，菜单和手柄保持屏幕尺寸。工具盘约束在阅读区域，收起后位于原收起按钮位置；独立夹具与真实阅读页已验证手柄拖动、停靠和重开保持，并增强了手柄视觉与抓取指针，其余窗口尺寸和 DPI 仍待验收。

默认指针，显式进入选文。右键移动超过5px临时平移，静止点击保留菜单；中键和Space+左键也平移。Ctrl+滚轮以鼠标锚点缩放40%–300%，Shift+滚轮水平滚动。输入框/Tiptap/IME拥有编辑按键。

Esc优先交给IME/模态，再关闭弹层、取消手势或结束编辑，最终回指针；不删除完成对象和问题材料。pointercancel/失焦清理手势。V/T/R/P/H/E/L切换工具，编辑器优先处理撤销。

打开选区菜单冻结文字和PDF坐标；取消选区自动隐藏操作条。AI动作只加入草稿。矩形区域支持图表/文字/公式混合，限定单页；包含个人标记明确标识。

引用预览冻结证据，定位后可返回阅读位置。聊天使用短用户气泡和开放回答排版，来源/材料/详情按需展开。

当前阅读页已将目录／书签／搜索／材料放在可收起的左导航，中央保留共享画板，右侧只显示问答。左导航宽度每书可调 220–320 px、初始 240 px；右问答沿用可调宽度。宽窗口可同时看原文、笔记内容和问答；窄窗口两侧使用交替抽屉，打开材料时收起问答，打开问答时先保存材料编辑草稿。旧版保存在右侧“笔记”状态的书籍打开后迁到左侧材料。左侧材料列出画布卡片、笔迹／文本／形状／关系及批注笔记；点击画布对象定位，显式“＋”加入本轮提问。对象列表分批展示，避免 5000 个对象同时创建 DOM；目前还没有跨类型统一排序与筛选。

标注与评论分离：没有评论的标注仍出现在列表，显示“无评论”；点击显示原文与“写评论”入口，不弹出空编辑器。评论详情分别提供“删除笔记”和“删除批注”。源标注已删除时保留来源展示和跳页，提示已删除，并禁用标注颜色修改／加入批注材料。

当前已增加：选中富文本笔记后可“展开编辑笔记”，在阅读工作区打开非模态编辑层，同时使用右侧问答和左侧材料。通过“放到画布”建立个人卡片，选中的卡片内直接编辑，未选中时显示轻量正文预览。三处编辑共享同一草稿；关闭按钮或编辑层内 Esc 先保存，失败不关闭。输入法组合期间不接管 Esc，正文内 Shift＋点击不触发卡片多选。移除个人卡片保留笔记；删除笔记会删除其位置与关系。摘录卡片仍展示原文／图片，评论使用同一富文本 Note；旧评论在首次点“编辑评论”时转入 Note，未操作前保留可见。旧个人卡片首次点“编辑笔记”也转入 Note；全工作区统一会话仍未完成。
