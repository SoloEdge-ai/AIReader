# UI 与交互规范

状态：当前规则；新版布局见[计划](plans/architecture-refactor.md)，未实现前不作为功能声明。

中性灰、细边框、系统字体、线性图标；浅/深/跟随系统，PDF 保留原色。工具图标18–20px、命中区至少36×36px；主题、排版、间距、焦点、圆角、阴影使用统一语义变量。

`apps/web/src/ui` 已集中 Icon、Popover 和浅深主题颜色 tokens；工作区操作菜单、对象格式、工具盘的添加／形状菜单与选区、模型浮层共用原生顶层 Popover。画笔设置保留首次选择、再次单击打开的工具行为，但复用同一浮层表面和视口定位规则。定位模块封装上下左右相对位置及视窗约束；菜单提供键盘焦点与 Esc 关闭，对象格式表单打开时聚焦第一个控件，并在工作区缩放后的布局提交后重新定位。横向及左右停靠的菜单／画笔设置已有浏览器回归测试。`WorkspaceObjectActions` 与 `WorkspaceRelationActions` 分别拥有对象格式、关系编辑和操作条，复用选区条的基础表面、按钮命中尺寸、边框和阴影；文字选区与已选源批注共用一份颜色配置及色点弹层，画布对象也用同一弹层并保留自定义色。操作条的更多布局约束尚待统一。画板内容随世界缩放，菜单和手柄保持屏幕尺寸。工具盘约束在阅读区域，收起后位于原收起按钮位置；独立夹具与真实阅读页已验证手柄拖动、停靠和重开保持，并增强了手柄视觉与抓取指针，其余窗口尺寸和 DPI 仍待验收。

默认指针，显式进入选文。右键移动超过5px临时平移，静止点击保留菜单；中键和Space+左键也平移。Ctrl+滚轮以鼠标锚点缩放40%–300%，Shift+滚轮水平滚动。输入框/Tiptap/IME拥有编辑按键。

Esc优先交给IME/模态，再关闭弹层、取消手势或结束编辑，最终回指针；关闭画笔设置的第一次 Esc 保留当前笔，第二次才回指针。不删除完成对象和问题材料。pointercancel/失焦清理手势。V/T/R/P/H/E/L切换工具，编辑器优先处理撤销。

PDF 页渲染完成不代表书籍工作区数据已载入。就绪前的画笔或对象编辑手势不捕获指针、不创建半成品，并显示“工作区尚未就绪”提示；就绪后才能开始。界面保留独立的工作区加载／保存状态，不能把等待误报为已保存。

保存失败与笔迹／导出错误固定在阅读容器的反馈层，不随 PDF 滚动；提示高于窄窗抽屉，限制高度并可内部滚动，在高缩放下仍能触达重试、备份和关闭按钮，同时避开底部工具盘。提示本身阻止点击穿透，避免误触被覆盖的内容。重试保存后仍可继续标注。

打开选区菜单冻结文字和PDF坐标；取消选区自动隐藏操作条。AI动作只加入草稿。矩形区域支持图表/文字/公式混合，限定单页；包含个人标记明确标识。

引用预览冻结证据，定位后可返回阅读位置。聊天使用短用户气泡和开放回答排版，来源/材料/详情按需展开。

当前阅读页已将目录／书签／搜索／材料放在可收起的左导航，中央保留共享画板，右侧只显示问答。左导航宽度每书可调 220–320 px、初始 240 px；右问答沿用可调宽度。宽窗口可同时看原文、笔记内容和问答；窄窗口两侧使用交替抽屉，打开材料时收起问答，打开问答时先保存材料编辑草稿。旧版保存在右侧“笔记”状态的书籍打开后迁到左侧材料。左侧画布材料在同一列表列出卡片、笔迹、文本、形状及关系，可按类型筛选、按物理页码或类型排序；点击定位，显式“＋”加入本轮提问。按页码时同页按类型和原始列表顺序排列，不声称页内视觉位置排序；无原文页位置的白板材料排在有页码材料之后。对象列表分批展示，避免 5000 个对象同时创建 DOM。批注和笔记仍在下方独立列表，还没有与画布对象合成同一条跨实体时间线。

标注与评论分离：没有评论的标注仍出现在列表，显示“无评论”；点击显示原文与“写评论”入口，不弹出空编辑器。评论详情分别提供“删除笔记”和“删除批注”。源标注已删除时保留来源展示和跳页，提示已删除，并禁用标注颜色修改／加入批注材料。

当前已增加：选中富文本笔记后可“展开编辑笔记”，在阅读工作区打开非模态编辑层，同时使用右侧问答和左侧材料。通过“放到画布”建立个人卡片，选中的卡片内直接编辑，未选中时显示轻量正文预览。三处编辑共享同一草稿；正在输入的编辑器不会被旧的被动快照覆盖，已保存且仍聚焦的编辑器可以接收真正的新版本，其他编辑器同步会话草稿。关闭按钮或编辑层内 Esc 先保存，失败不关闭。输入法组合期间不接管 Esc，正文内 Shift＋点击不触发卡片多选。移除个人卡片保留笔记；删除笔记会删除其位置与关系。摘录卡片仍展示原文／图片，评论使用同一富文本 Note；旧评论在首次点“编辑评论”时转入 Note，未操作前保留可见。旧个人卡片首次点“编辑笔记”也转入 Note；全工作区统一会话仍未完成。

桌面关闭窗口时先冻结界面并保存当前书籍的笔记与画板草稿；失败则保留窗口、解冻编辑并提示重试，成功后才退出。普通浏览器开发调试仍使用未保存草稿的离开提示。
