# AIReader × LiquidText：单书深度阅读工作台

状态：`codex/liquidtext-alignment` 集成中。实施依据为用户确认的完整计划；本文件记录代码对应范围和交付门槛，不把尚未验收的界面当作发布完成。

## 产品任务

用户在同一窗口完成：阅读 PDF → 摘录文字或图表 → 摆放与分组 → 比较与建立关系 → 写一篇可引用多处来源的笔记 → 把选定材料冻结到 AI 问题 → 核对并回到原文 → 下次继续。以 LiquidText 的并排文档／工作区、低摩擦摘录、关系可见与单击回源为对照，不复制其全部多文档功能。本版只处理单书，沿用原有绘图、模型选择、图片输入和退出保护。

## 已接入的实现切片

| 切片 | 代码位置 | 需要验收的行为 |

## 必须完成的验收

1. 使用生成的三页技术材料，在 1280×720、1440×900、1920×1080 验证四套基础外观、双栏与窄窗。
2. 摘录文字、公式和图表，放入两组，移动／折叠／排列并撤销；两份摘录比较、聚焦原始 PDF 并回到阅读位置。
3. 创建笔记、关联三份来源、输入表格和公式、关闭重开；模拟保存失败、版本冲突和响应丢失，确认草稿与冻结来源不丢失。
4. 选中材料时仅预览 AI 连线；明确加入后查看冻结清单与实线，编辑原材料后仍发送原快照；发送后清理草稿线。
5. 导出、归档并恢复为独立副本；确认来源图片、引用、分组、位置、关系与 PDF 坐标。
6. 运行 typecheck、Core HTTP／PDF／画布／笔记／AI 相关测试、浏览器验收、Windows Portable 与 Setup 构建及实际启动和关闭重开验证。记录构建 SHA、格式版本、安装版本和校验和。

用户已明确允许放弃旧笔记／工作区格式兼容。本实现拒绝旧数据库和 v1–v3 归档；不会自动删除现有目录。公开截图只使用生成材料。
